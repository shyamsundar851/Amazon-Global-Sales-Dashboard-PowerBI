# 📊 Amazon Global Sales Dashboard – Power BI

A fully interactive Power BI dashboard analyzing Amazon’s global sales performance across regions, segments, and product categories. This report provides insights into sales trends, profitability, customer behavior, and KPI performance.

---

## 🚀 **Project Overview**

This Power BI project visualizes Amazon’s sales data from 2012–2015.
It helps stakeholders quickly understand **total sales, product movement, customer profitability, top-performing products, and global market distribution**.

The dashboard is designed with a professional layout using KPIs, charts, and maps for easy storytelling.

---
